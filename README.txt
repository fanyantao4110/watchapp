腕表应用库 · 本地静态页面
===============================
页签:
  [可下载]   目前为空, 显示「应用会陆续上架, 敬请期待」。
             要上架就离线改 index.html 里的 DOWNLOADED 数组
             (文件上部有字段示例), 保存刷新即出现。
  [悬赏中]   现站上全部 156 个应用, 卡片右侧有「提交」按钮。

提交流程:
  点「提交」→ 面板显示应用名 + 收件邮箱
  → 点「确认提交」直接唤起邮件客户端, 收件人/标题/正文自动填好
  → 邮件正文里只需补上你的手表型号, 并附上已签名 hap 与收款码
  → 核对通过发放 0.1 元
  页面上不做设备选择, 型号在邮件里写。

不显示价格 · 不显示来源站点

目录:
  index.html    单文件页面, 数据内嵌, 双击即可离线打开
  icon/         156 个图标
  shot/         436 张截图
  apps.json     抓取清洗后的数据 (页面未使用价格字段)
  devnames.json 设备代号 → 型号名

快捷键: / 聚焦搜索, Esc 关闭弹层
